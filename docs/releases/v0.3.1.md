# Weavatrix Online 0.3.1

Weavatrix Online 0.3.1 keeps the verified 52-tool MCP contract and makes the
connector maintainable under the same strict architecture limits it can enforce
for other repositories.

## Release proof

- Split advisory inventory, cache, malware rules, dependency discovery, file
  scanning, and report construction into explicit modules.
- Enforce a strict modular ports-and-adapters contract with zero architecture
  baselines or exceptions.
- Keep every production source file at or below 300 physical lines and every
  production function at or below 100 physical lines.
- Remove the nonexistent `index.js` package entry point; this package is an MCP
  executable, not a JavaScript library facade.
- Publish the architecture contract and document both write gates:
  `WEAVATRIX_ALLOW_SOURCE_EDITS=1` and `WEAVATRIX_ALLOW_TEST_RUNS=1`.
- Preserve the source-free, preview-before-sync wire boundary and the same
  seven Online tools.

The release remains MIT-licensed and composes `weavatrix-js ^0.3.15` with
`weavatrix-refactor ^0.1.3`.
